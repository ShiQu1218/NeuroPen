# Roadmap

Last updated: 2026-03-14

This roadmap is directional, not a guarantee. It exists to show likely areas of investment and where external contributors can help.

## Near-Term Priorities

### 1. Lower contribution friction

- Keep developer docs current and explicit
- Continue breaking large controllers into reviewable modules
- Identify safe contribution areas that do not require full-stack context

### 2. Improve confidence in changes

- Add targeted regression tests around routing, settings persistence, and backend commands
- Expand validation coverage where current checks are weak or slow to diagnose
- Document manual verification steps for Windows-specific workflows

### 3. Improve project discoverability

- Add short animated demos for major workflows
- Keep release notes and changelog entries current
- Make contribution entry points easier to find from the repository front page

### 4. Improve community workflow

- Maintain issue and PR templates
- Curate starter tasks and clearer change scopes
- Keep design and behavior changes aligned with OpenSpec

## Non-Goals

- Immediate cross-platform parity with macOS or Linux
- Replacing the current Tauri desktop architecture in the short term

# Code of Conduct

This project expects professional, respectful collaboration from maintainers, contributors, and users.

## Expected Behavior

- Be respectful in technical disagreement.
- Focus feedback on the work, not the person.
- Share context, repro steps, and evidence when reporting problems.
- Assume good intent, but be precise when behavior or claims are incorrect.
- Respect privacy and security boundaries when discussing logs, prompts, screenshots, audio, or user data.

## Unacceptable Behavior

- Harassment, insults, discrimination, or threats
- Bad-faith trolling or repeated non-constructive disruption
- Publishing private information without permission
- Abusive language in issues, PRs, discussions, or review comments

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates these expectations. Repeated or severe violations can lead to temporary or permanent removal from project spaces.

## Reporting

If you encounter a serious conduct issue, open a private maintainer contact channel if one is available. If no private channel is available, open a minimal public issue without sensitive details and ask for maintainer follow-up.
